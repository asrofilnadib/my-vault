## Introduction
Gue memiliki case menarik dimana gue dikasih pinjem Hosting temen gue. Dan gue coba untuk explore penggunaan FTP Client.

## Apa Itu FTP Client?
Digunakan untuk menghubungkan komputer lokal ke server hosting melalui protokol **FTP (File Transfer Protocol)** . FTP Client bertindak sebagai "jembatan" antara komputer lo dan server hosting, sehingga dapat dengan mudah mengelola file di server tanpa harus menggunakan antarmuka web seperti cPanel.
