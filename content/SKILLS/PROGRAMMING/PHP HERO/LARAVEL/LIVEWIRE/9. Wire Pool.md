## Wire:Pool
Polling adalah teknik yang digunakan dalam aplikasi web untuk mengirim permintaan secara berkala untuk pembaruan. Ini adalah cara sederhana untuk menjaga halaman tetap terkini tanpa memerlukan teknologi yang lebih canggih seperti _WebSockets_. Bisa dikatakan Realtime Application.

"Memperbarui data tanpa refresh".

Sederhananya gunakan koding berikut :

```html
<div wire:poll>
	Subscribers: {{ $count }}
</div>
```

Kode diatas tanpa reload, kita cukup mengunjungi halaman, otomatis akan berubah.

## Background
Keep alive membuat kodingan kita bekerja tanpa kita buka halamannya, Anda dapat menambahkan pengubah .keep-alive ke wire:poll:

```html
<div wire:poll.keep-alive>
	Subscribers: {{ $count }}
</div>
```
