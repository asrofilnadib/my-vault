## Wire:Navigate
`wire:navigate` membuat navigasi halaman lebih cepat, memberikan pengalaman seperti SPA bagi pengguna Anda.

Di bawah ini adalah contoh sederhana :

```html
<nav>
	<a href="/" wire:navigate>Dashboard</a>
	<a href="/posts" wire:navigate>Posts</a>
	<a href="/users" wire:navigate>Users</a>
</nav>
```

Dengan menggunakan `wire:navigate` ini membuat aplikasi web kita lebih interaktif dan tanpa reload halaman penuh.
