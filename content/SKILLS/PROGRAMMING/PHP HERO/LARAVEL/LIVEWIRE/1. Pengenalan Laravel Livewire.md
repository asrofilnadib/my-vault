## Introduction
Membuat aplikasi moden itu sulit. Seperti _Vue_ dan _React_ sangat powerful, namun dengan kompleksitasnya mereka membuat workflow jadi ruwet.

Livewire itu Fullstack untuk Laravel yg digunakan untuk membangun interface yg dinamis _Tanpa_ harus meninggalkan kenyamanan Laravel.

## Fitur
Misi dari Livewire untuk membangun efisiensi dan kenyamanan dalam mengembangkan website.

### 1. Form
Membuat form termasuk fitur utama livewire. Validasi secara realtime dan upload file akan menjadi sangat mudah dilakukan.

### 2. Table
Livewire sangat cocok untuk membuat table. Menampilkan data, paginasi, filter data, jauh lebih mudah.

### 3. Chart
Hal mudah bila ingin membuat chart secara realtime.Hubungkan ke library chart dan biarkan livewire menampilkannya!

### 4. Upload File
Mudah dalam hal mengunggah file dan gambar(pratinjau gambar).

### 5. Lazy Load
Lazy loading adalah teknik pengoptimalan dalam pemrograman komputer yang memungkinkan aplikasi untuk menunda atau menunda pengambilan atau pembuatan sumber daya hingga saat diperlukan. Istilah ini sering digunakan dalam konteks pengembangan web dan pengembangan perangkat lunak pada umumnya.
