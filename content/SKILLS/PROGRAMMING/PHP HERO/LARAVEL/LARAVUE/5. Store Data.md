## Logicnya
```javascript
import axios from 'axios';
export default {
    data(){
        return {
            company: '',
            role: '',
            platform: '',
            apply_at: '',
            status: '',
            link: '',
            description: ''
        };
    },
    methods: {
        store() {
            const formData = {
                company: this.company,
                role: this.role,
                platform: this.platform,
                apply_at: this.apply_at,
                status: this.status,
                link: this.link,
                description: this.description
            };

            axios.post('/api/store', formData)
                .then(res => {
                    Swal.fire({
                        title: "Berhasil",
                        icon: "success",
                        text: res.data.message
                    });
                    this.resetForm();
                })
                .catch(error => {
                    console.log("error nih")
                });
        },
        resetForm() {
            this.company = '';
            this.role = '';
            this.platform = '';
            this.apply_at = '';
            this.status = '';
            this.link = '';
            this.description = '';
        }
    }
};
```

Kesimpulan:
1. import axios
2. apapun data yg akan kita store/get maka ditaruh di function data() trus di return
3. buat methods store dan resetForm(digunakan bila ingin menghilangkan value ketika store. Ini opsional).
4. di const formData, untuk memanggil properti kita pakai this.

## Backend nya
```php
public function store(Request $req){
	DB::table('applications')
		->insert([
		   'company' => $req->company,
			'role' => $req->role,
			'platform' => $req->platform,
			'apply_at' => $req->apply_at,
			'status' => $req->status,
			'link' => $req->link,
			'description' => $req->description,
		]);

	return response()->json([
		'message' => 'Berhasil membuat data!'
	]);
}
```
