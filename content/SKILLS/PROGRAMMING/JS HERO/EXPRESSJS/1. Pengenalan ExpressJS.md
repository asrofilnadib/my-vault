## Introduction
ExpressJS adalah framework berbasis Javascript. Framework open source ini dibuat oleh TJ Holowaychuk pada tahun 2010 lalu. Framework satu ini sebagai [Back End](https://www.dicoding.com/blog/apa-itu-back-end/) yg memiliki tugas seperti pengelolaan routing dan session, permintaan HTTP, penanganan error, serta pertukaran data di server.

Selain itu ExpressJS memiliki arsitektur [MVC (Model View Controller)](https://www.dicoding.com/blog/apa-itu-mvc-pahami-konsepnya/) Jadi untuk para programmer php dengan mudah mempelajari & menggunakan expressJS.

Yg membuat menarik framework ini adalah **tidak memiliki aturan ketat mengenai penulisan kode**. Berbeda dengan framework seperti let's say laravel yg memiliki aturan ketat dalam penulisan kode.

ExpressJS memiliki pendekatan Un-opinionated yg artinya pemrogram punya kebebasan dalam menentukan metode yang akan digunakan untuk mengeksekusi suatu perintah.

## Kelebihan
- Bebas menentukan sendiri arsitektur dan struktur website yang akan dikembangkan
- Ukuran framework lebih kecil dan ringan, karena hanya berisi package inti
- Kinerja website yang dihasilkan jadi lebih baik, mengingat ringannya framework

## Kekurangan
- Diperlukan keahlian khusus untuk membuat, mengelola, dan merawat arsitektur website
- Terlalu banyak pilihan plugin dan library untuk digunakan, bisa membingungkan bagi sebagian orang
- Pilihan metode pengembangan yang berbeda-beda, sehingga kurang cocok untuk pemula

## Manfaat
### Memperbaiki Error Dengan Mudah
Express.js bisa mengatasierror dengan lebih cepat berkat mekanisme debugging yang diterapkan. Caranya lewat metode **debug** yang menyimpan informasi mulai dari routing, fungsi middleware, dan sebagainya.

### Mempersingkat Proses Pengembangan
Integrasi dengan MERN,MEVN, MEAN membuatnya mempersingkat proses pengembangan. Selain itu memiliki dukungan komunitas yg banyak.

### Menekan Biaya Pengembangan
Menggunakan Express.js artinya dapat menekan biaya yang diperlukan untuk mengembangkan website. Pasalnya, ia adalah framework open source yang bisa digunakan secara bebas tanpa perlu meminta perizinan lisensi.
