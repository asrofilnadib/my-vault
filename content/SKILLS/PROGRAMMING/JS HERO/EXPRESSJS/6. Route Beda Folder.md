## Introduction
Ada kalanya kita memisahkan routes ke dalam file. Hal ini membuat kodingan kamu lebih rapih. Bayangkan jika ada 25 routes di dalam file `app.js`?

Buat folder routes di root dan buat file `web.js` (nama file bebas). Kita akan menggunakan express router ya!

web.js

```javascript
const express = require("express");

const router = express.Router();

router.get("/", (req,res) => {
	res.render('index', {
		menu: "Dashboard"
	});
});

router.get("/create", (req, res) => {
	res.render("create", {
		menu: "Tambah Data"
	});
});

module.exports = router;
```

jangan lupa export modulnya hehe!

maka file app.js akan seperti ini

```javascript
const express = require("express");
const path = require("path");
// Load routes nya
const webRoute = require("./routes/web.js");

const app = express();

app.set("view engine", "ejs");
app.set("views", "views");

app.use(express.static(path.join(__dirname, 'public')));

// Pakai route nya
app.use(webRoute);

app.listen(3000, () => {
	console.info('server is run!');
});
```
