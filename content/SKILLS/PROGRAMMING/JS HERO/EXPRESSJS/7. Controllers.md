## Introduction
Terlalu banyak _logic_ di route itu tidak bagus juga. Karena tugas route hanya perutean website kita saja, bukan tempat untuk menaruh logic dari aplikasi. Logic aplikasi kita harus ditaruh di COntroller.

Buat folder `controllers` di root, beri nama `biodata.js` (contoh) biodata.js

```javascript
exports.index = (req, res, next) => {
	res.render('index', {
		menu: "Dashboard"
	});
};

exports.create = (req, res, next) => {
	res.render("create", {
		menu: "Tambah Data"
	});
};
```

Logic diatas contoh kita untuk render view saja. Kedepannya bisa digunakan untuk tambah data, update hingga hapus.

Sebelumnya di `routes/web.js` kita seperti ini web.js lama

```javascript
const express = require("express");

const router = express.Router();

router.get("/", (req,res) => {
	res.render('index', {
		menu: "Dashboard"
	});
});

router.get("/create", (req, res) => {
	res.render("create", {
		menu: "Tambah Data"
	});
});

module.exports = router;
```

Ubah menjadi seperti ini web.js baru

```javascript
const express = require("express");
const biodataController = require("../controllers/biodata");

const router = express.Router();

router.get("/", biodataController.index);
router.get("/create", biodataController.create);

module.exports = router;
```

Jangan lupa untuk load controllernya ya di route!
