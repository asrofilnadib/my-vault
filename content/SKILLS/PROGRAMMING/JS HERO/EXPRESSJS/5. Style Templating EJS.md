## Introduction
Dilansir dari Codepolitan, EJS (**Embedded JavaScript**) memungkinkan kita untuk menggabungkan kode JavaScript dengan HTML secara langsung di dalam file-template.

## Installing
```shell
npm install ejs
```

## Templating
### Partials
Pisahkan beberapa bagian seperti header, navbar, sidebar, dan footer dan include ketika dibutuhkan saja ya.

### Pages
Index.js

```javascript
<%- include('./layouts/header.ejs') %>
<%- include('./layouts/sidebar.ejs') %>
<%- include('./layouts/navbar.ejs') %>
<%- include('./layouts/breadcrumb.ejs') %>
// Codingan kamu
<%- include('./layouts/footer.ejs') %>
```

### Views Calling
Jngan lupa panggil viewsnya ya

app.js

```javascript
const express = require("express");
const path = require("path");

const app = express();

app.set("view engine", "ejs");
app.set("views", "views");

app.use(express.static(path.join(__dirname, 'public')));

app.get("/", (req,res) => {
	res.render('index', {
		menu: "Dashboard"
	});
});

app.listen(3000, () => {
	console.info('server is run!');
});
```
