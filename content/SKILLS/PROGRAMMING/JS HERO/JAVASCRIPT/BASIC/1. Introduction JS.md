## Apa Itu Javascript?
- Javascript adalah suatu bahasa pemrograman web.
- Bisa menghitung, manipulasi html atau css hingga validasi data.

## Komponen Web
1. HTML: untuk define isi web.
2. CSS: pewarnaan layouts.
3. Javascript: behavior suatu web.

## Contoh

```html
<html>
<body>
	<div id="demo"></div>

	<script>
		document.getElementById("demo").innerHTML = "Hello JavaScript";
		document.getElementById("demo").style.fontSize = "35px";
	</script>
</body>
```

## Peletakan
- didalam tag `<script>` atau di dalam `<head>`.
- old javascript menggunakan atribut `<script type="text/javascript">`, saat ini tidak perlu penambahan atribut tsb karena secara default di script html itu javascript.
