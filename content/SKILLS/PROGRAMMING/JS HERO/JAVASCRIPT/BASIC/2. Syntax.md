#Tech 
## Type Value
Di javascript terdapat 2 tipe value:
1. Literals (nilainya tetap)
2. Variables (nilainya berubah)

## Literals
Contoh
```javascript
10.00
1000

"Budi"
'Budi'
```

## Variables
```javascript
let x;  
x = 6;
```

## Identifiers
- diawali dengan huruf, underscore ( _ ) atau dollar ($).
- bisa berisi angka diawal.
- termasuk case sensitif.

## Macam-macam Style Coding
- Camel Case = FullName
- Lower Camel Case = fullName
- Underscore = full_name

Note: Javascript programmer cenderung menggunakan Lower Camel Case

## Penggunaan titik koma (;)
- Bisa digunakan bisa tidak.
- Direkomendasikan pakai semicolon ( ; )
