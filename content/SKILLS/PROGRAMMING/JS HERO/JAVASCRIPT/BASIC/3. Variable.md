## Basic
- Variable adalah wadah untuk data.
Bisa di define kedalam 4 cara
- let (modern JS)
- const (modern JS)
- var (not recommended) - digunakan sebelum 2015 namun masih tetap bisa dipakai
- automatically (not recommended)

Bisa di declare menggunakan dollar ($), underscore ( _ ) dan lain-lain.

Contoh automatically variable

```javascript
x = 5;  
y = 6;
```

### Kapan Menggunakan Var, Let, Const
- selalu declare variable.
- pakai const bila value tidak berubah.
- pakai let bila value berubah-ubah.
- jangan gunakan var.

## Data Type
- String ditulis didalam kutip satu atau dua.
- Number ditulis tanpa kutip.

### One Statement Many Variable
Kita bisa define banyak variable dalam 1 titik koma.

```javascript
let person = "John Doe", carName = "Volvo", price = 200;
```

## Let
- Let introduce di ES6 (2015)
- Let have block scope.
- Let harus di declare sebelum digunakan.

Contoh Block Scope:

```javascript
{  
  let x = 2;  
}  
// x can NOT be used here
```
variable x tidak bisa diakses diluar blok.

Intinya Let lebih disarankan.
