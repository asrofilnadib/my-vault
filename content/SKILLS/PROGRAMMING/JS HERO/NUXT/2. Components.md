## Introduction
Component itu suatu bagian yg bisa dipakai kembali (reusable). Seperti: tombol, notifikasi, menu, dan lain-lain. Cara membuat nya di Nuxt Mudah.

## Create Component
Kita cukup membuat folder components (bila belum ada), lalu buat file nya.

Alert.vue

```vue
<template>
	<span style="background-color: aqua;">
		<slot></slot>
	</span>
</template>
```

Jangan lupa load di entry point nya (App.vue)

```vue
<template>
	<div>
		<NuxtRouteAnnouncer />
		<NuxtWelcome />
		<AppAlert>
			Apa kabar?
		</AppAlert>
	</div>
</template>
```

Ngga harus di import?

Di Nuxt 2 keatas, Kita tidak perlu import component karena sudah disediakan oleh Nuxt 3 fitur "Auto Import" jadi ngga perlu lagi tuh import component. Selagi kita menempatkan file di folder components itu akan terbaca secara otomatis.
