## Introduction
load file terdapat 2 cara:
- **`public/`** : Digunakan untuk file statis yang tidak perlu diproses, seperti gambar atau dokumen yang langsung diakses via URL.
- **`assets/`** : Digunakan untuk file yang memerlukan pemrosesan oleh Webpack, seperti gambar yang dioptimalkan, SASS/SCSS, atau font dinamis.

## Cara load

```vue
<img src="/img/nama_file.png">
<img src="~/assets/img/nama_file.png">
```

Note: 
- penggunaan aset diawal menggunakan tanda `~`
- bila folder tidak ada silahkan buat!
