## Apa Itu VueJS?
Selama bertahun-tahun, Javascript telah memberi warna pada sebuah halaman web, membuat halaman web menjadi _lebih dinamis_ dan powerfull. Para developer web juga memiliki andil yg sangat besar untuk mempopulerkan framework javascript ini melalui karya-karya nya.

VueJS hadir dengan beberapa keunggulan :

1. _Approachable_ (pendekatan yg mudah)
2. _Maintainable_ (pemeliharaan yg mudah)
3. _Versatile_ (serba guna)
4. _Reactive_ (terhadap perubahan data)
5. _Performant_ (ukuran kecil performa cepat)
6. _Testable_ (pengujian yg mudah)

Selain itu VueJS juga menyediakan antarmuka VueCli untuk membangun website yg lebih cepat dan mudah.

Vue.js merupakan framework javascript _progresif_ yg digunakan untuk membangun tampilan _user interface_ dengan mengacu pada arsitektur _MVC(Model View Controller)_.

VueJS merupakan proyek open-source dengan lisensi MIT yg dibuat oleh Evan You pada Februari 2014. Sebelumnya dia bekerja di Google dalam proyek AngularJS. Banyak konsep dalam AngularJS yg diadaptasi di VueJS seperti expression dan directive.
