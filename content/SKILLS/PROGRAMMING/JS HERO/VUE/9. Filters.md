## Introduction
VueJS memberikan keleluasaan untuk mendefinisikan filter yg dapat digunakan untuk melakukan format pada teks.

**app.js**

```javascript
let app = new Vue({
el: '#app',
data: {
    pesan: 'Filter Teks'
},
filters: {
    kapital(value){
        if(!value) return ''
        value = value.toString()
        return value.toUpperCase()
    }
}
})
```

**index.html**

```html
<div id="app">
    <p>{{ pesan | kapital }}</p>
</div>
```

Secara teknis, untuk membuat filter kita akan menempatkan di 2 tempat. di htmlnya dan di vue nya.

Pelajari lebih lanjut [disini](https://v2.vuejs.org/v2/guide/filters.html)
