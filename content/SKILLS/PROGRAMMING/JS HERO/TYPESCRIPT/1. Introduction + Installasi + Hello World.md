## Introduction
Bayangkan kamu sedang membangun sebuah rumah. Kamu bisa saja langsung mulai memasang batu bata tanpa gambar atau rencana, tapi hasilnya bisa berantakan, sulit diperbaiki, dan rawan kebocoran. Nah, itulah seperti menulis JavaScript - fleksibel, tapi rentan kesalahan.

**TypeScript** hadir seperti arsitek yang membantu kamu merancang rumah itu dengan rancangan yang jelas, aturan yang konsisten, dan peringatan dini jika ada yang tidak sesuai. TypeScript adalah **superset dari JavaScript** yang menambahkan **static typing** — artinya kamu bisa mendeklarasikan tipe data untuk variabel, parameter fungsi, dan lainnya.

## Kenapa Pakai TypeScript?
- **Deteksi kesalahan lebih awal** saat development, bukan saat runtime.
![[Pasted image 20250905205631.png]]
Gue ngeset string tapi value nya number. sudah terdeteksi di vscode nya.
![[Pasted image 20250905205743.png]]
Beda hal di JS, dia terima aja walaupun di declare diawal string. Lain hal dengan Typescript.

- **Lebih mudah di-maintain** karena kode lebih jelas dan terdokumentasi sendiri.
- **Intellisense yang lebih baik** di editor seperti VS Code.
- **Scalable** untuk proyek besar dan tim developer.

## Instalasi
Download nodejs terbaru lalu ketik perintah:
`npm install -g typescript`

Buat kode dengan extensi file `.ts`
![[Pasted image 20250905210001.png]]
Lalu compile dengan perintah `tsc nama_file.ts`. Hasilnya akan menjadi `nama_file.js`
