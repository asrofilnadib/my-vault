## Introduction
Sebelum ngoding, biasanya kita setup mulai dari initialisasi hingga instalasi plugin pendukung.

## Setup
- Seperti biasa kita akan initialisasi project dengan ketik perintah `npm init -y`;
- Install typescript (sebelumnya kan kita sudah install cli nya) dengan ketik perintah `npm install --save-dev typescript`
- Terakhir ketik perintah `tsc --init` maka struktur folder akan seperti gambar dibawah.

## Automatic Run
Agar automatic run ts nya kita biasa pakai nodemon.

`npm install --save-dev nodemon`

## Setting Nodemon Script
![[Pasted image 20250905212446.png]]
Set Nodemon Script CLI nya di package json. Sesuaikan dengan nama file kalian ya.

## Jangan Lupa Build
![[Pasted image 20250906062545.png]]
Setelah kita coding ts, jangan lupa untuk ketik perintah `npm run build`. maka hasil build akan tersimpan di folder `dist`.

Untuk melihat hasil silahkan ketik perintah `npm start`;
