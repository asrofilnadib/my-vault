## Introduction
TS memperkenalkan sistem *static typing* yg memungkinkan kita untuk mendefinisikan tipe data variable sejak awal. Static Typing adalah konsep dalam pemrograman yang mengharuskan tipe data suatu variabel didefinisikan dan diperiksa pada waktu kompilasi (compile time), bukan saat program dijalankan (runtime).

## String
`let nama: string = "Andaru";`
Digunakan untuk menyimpan teks.

## Number
`let umur: number = 24;`
Digunakan untuk menyimpan angka bulat dan float (koma).

## Boolean
`let pekerja: boolean = true;`
Hanya menyimpan 2 nilai: true dan false.

## Any
`let kata_mutiara: any = "Bisa string, bisa number" + 123;`
Dapat menyimpan nilai dengan tipe data apapun.

## Array
`let hobi: string[] = ["Makan","Tidur"];`
Menyimpan banyak nilai dalam 1 variable.

## Object
```ts
let fav_food: object = {
    nama: "nasi goreng",
    level: "tidak pedas"
};
```
Menyimpan banyak nilai dalam 1 variable. dalam bentuk object.
