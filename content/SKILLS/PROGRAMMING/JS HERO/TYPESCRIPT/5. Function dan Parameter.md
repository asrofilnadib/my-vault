## Introduction
Function di TS adalah blok kode yg digunakan untuk menjalankan tugas tertentu.

## Function params dan return
```ts
function tambah(a: number, b: number): number { 
	return a + b; 
} 

console.log(tambah(8, 3));
```
Ini tipe data yg sering kita gunakan.

## Function Void
```ts
function sapaUser(nama: string = "User"): void { 
	console.log(`Halo, ${nama}!`); 
} 
sapaUser(); // Output: Halo, User! 
sapaUser("Mamat"); // Output: Halo, Mamat!
```
Intinya, `void` mengomunikasikan bahwa tujuan suatu function bukanlah untuk menghasilkan nilai, melainkan untuk melakukan suatu tindakan.

## Optional Params
```ts
function perkenalan(nama: string, umur?: number): void {
  if (umur) {
    console.log(`Halo, nama saya ${nama} dan saya berusia ${umur} tahun.`);
  } else {
    console.log(`Halo, nama saya ${nama}.`);
  }
}

perkenalan("Mamat", 22); // Output: Halo, nama saya Mamat dan saya berusia 22 tahun.
perkenalan("Mamat"); // Output: Halo, nama saya Mamat.
```
