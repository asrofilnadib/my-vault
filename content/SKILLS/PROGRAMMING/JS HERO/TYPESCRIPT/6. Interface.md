## Introduction
Penggunaan interface untuk mendefinisikan struktur data di object agar lebih jelas. Tujuan nya agar struktur data lebih konsisten. Berikut Implementasinya.

## Implementasinya
```ts
interface User {
  name: string;
  age: number;
  isAdmin: boolean;
}

const user1: User = {
  name: "Andaru Gapake Ganteng",
  age: 24,
  isAdmin: true,
};

console.log(user1.name);
```

## Opsional Property?

```ts
interface Product {
  name: string;
  price: number;
  description?: string; // Optional property
}

const product1: Product = {
  name: "Laptop",
  price: 15000000,
};

console.log(product1.description); // Output: undefined (karena tidak diisi)
```
