## Introduction
- Literal Types memungkinkan untuk menetapkan nilai yg spesifik ke suatu variable.
- Enum mendefinisikan nilai tetap (konstanta) yg lebih mudah dibaca.

## Literals Types
```ts
let pekerjaan: "kurir" | "programmer";

pekerjaan = "kurir";

console.log(pekerjaan);
```
Membatasi variable hanya berisi nilai tertentu.

## Enum
```ts
enum PaymentStatus {
  Pending = "PENDING",
  Success = "SUCCESS",
  Failed = "FAILED"
}

let statusTransaksi: PaymentStatus = PaymentStatus.Success;
console.log(statusTransaksi); // Output: SUCCESS
```
Baik digunakan bila ingin hasil output lebih mudah dibaca.

## Kesimpulan
Gue lebih prefer ke literals type. karena pendekatan nya sama dengan enum di datatable.
