## Introduction
Pelajari jurnal typescript terlebih dahulu lalu kembali kesini. Sebelumnya kenapa gue tertarik mempelajari NestJS? karena banyak demand di pasar bahwa NestJS dibutuhkan. 

## NestJS - A progressive Node.js framework
**NestJS** adalah sebuah framework khusus Backend menggunakan **Node.js**, yang dirancang agar mudah dikembangkan dan terstruktur dengan baik.

![[Pasted image 20250913221934.png]]

Extensible: sangat mudah menambahkan fitur baru tanpa mengubah bagian lain karena sistemnya dibagi menjadi bagian kecil.

Versatile: dapat digunakan ke berbagai jenis aplikasi seperti web biasa, rest api, microservice, dan lain-lain.

Progressive: memperkenalkan pattern kode yg terbukti cocok di nodejs.

## Install
Untuk proses install sangat sederhana. cukup ketik perintah dibawah:
```bash
npm i -g @nestjs/cli
nest new nama-project
npm run start:dev
```

kunjungi localhost:3000
## Kesimpulan
- **Support TypeScript** tapi tetap bisa pakai JavaScript biasa
- Pakai Express (default) atau Fastify sebagai dasar
- Menyediakan struktur siap pakai di atas framework tersebut
- Memberi struktur yang membuat kode lebih mudah diuji, di-maintain, dan dikembangkan
- Terinspirasi dari Angular

**Intinya**: NestJS = Struktur rapi + Fleksibilitas tinggi + Cocok untuk proyek besar maupun kecil.
