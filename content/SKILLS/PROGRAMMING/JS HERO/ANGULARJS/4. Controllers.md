## Introduction
Kita telah mempelajari fungsi operasi pengolahan sederhana. Kemudian bagaimana jika kita ingin menerapkan fungsi yg lebih kompleks? Jawabannya adalah dengan menggunakan _Controller!_

Sebuah controller merupakan fungsi konstruktor pada object Javascript yg berisi fungsi, atribut, dan behavior.

## Persiapan Menggunakan Controller
Untuk menerapkan konsep _MVC(Model View Controller)_ di AngularJS setidaknya diperlukan dua file, dimana satu file HTML yg akan berfungsi sebagai view dan file js berfungsi sbg controller.

### Format Penulisan
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Latihan Angular</title>
    <script src="angular.min.js"></script>
    <script>
        angular.module('belajar', []).controller('kontroller', function($scope){
            $scope.kata = 'Ini dari Controller!'
        })
    </script>
</head>
<body ng-app="belajar">
    <h1>Latihan AngularJS</h1>
    <div ng-controller="kontroller">
        <p>{{ kata }}</p>
    </div>
</body>
</html>
```

## Array
```html

<html lang="en">
<head>

        angular.module('belajar', []).controller('kontroller', function($scope){

    <h1>Latihan AngularJS</h1>

```

## Array Bertingkat
```html
<!DOCTYPE html>
<html lang="en">
<head>

        angular.module('belajar', []).controller('kontroller', function($scope){

</html>
```

## Logika If Else
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Latihan Angular</title>
    <script src="angular.min.js"></script>
    <script>
        angular.module('belajar', []).controller('kontroller', function($scope){
            $scope.hasil = function(){
                if($scope.isi === 'Slamet'){
                    return 'jawaban kamu : '+$scope.isi+' BETUL!'
                }else{
                    return 'Jawaban kamu salah!'
                }
            }
        })
    </script>
</head>
<body ng-app="belajar" ng-controller="kontroller">
    <h1>Latihan AngularJS</h1>
    <p>Siapa bapak kamu? <input type="text" ng-model="isi"></p>
    <p>{{ hasil() }}</p>
</body>
</html>
```
