## Introduction
Angular JS adalah framework javascript yg dikembangkan oleh Google dan banyak digunakan pada produk-produk yg dibuat oleh Google. Diperkirakan ada 12.000 website dan beberapa contoh website populer telah menggunakan AngularJS adalah Intel, ABC News, Sprint, NBC, Walgreens, dsb.

AngularJS telah menjadi salah satu standarisasi untuk keperluan pembuatan aplikasi _web dinamis dari sisi client_, karena kemudahan dan kecepatannya dalam melakukan komunikasi server ke client.

## Mengapa Menggunakan AngularJS?
HTML yg merupakan bahasa umum pembuatan web itu _tidak didesain untuk keperluan website dinamis_. Website statis merupakan website yg _hanya menampilkan informasi biasa tanpa fungsi-fungsi khusus_. Website dinamis memungkinkan dimasukannya fungsi tertentu supaya _lebih menarik_.

Untuk itulah dibutuhkan suatu script khusus untuk membuat website tersebut menjadi dinamis, salah satunya dengan menggunakan Javascript. Script-script yg dibuat dengan Javascript akan menjadi lebih atraktif dan menarik.

## Apa itu AngularJS?
AngularJS merupakan _frontend framework_ dengan basis kode Javascript. Dikembangkan pertama kali oleh _Google_ untuk membangun aplikasi web yg dinamis. AngularJS dirilis pertama kali pada tanggal 20 Oktober 2010, dan dikembangkan menggunakan konsep arsitektur _MVC(Model View Controller)_ dan _MVVM(Model View View Model)_

AngularJS dapat memberikan fungsi yg lebih pada tag html sehingga menghasilkan suatu aplikasi yg lebih ekspresif dan mudah untuk dikembangkan.

## Kelebihan AngularJS
1. Bersifat Open Source sehingga dapat digunakan dengan gratis
2. Sudah digunakan oleh banyak developer
3. Compatible dengan banyak browser
4. Pendekatan MVC pada arsitektur AngularJS memungkinkan mempermudah developer
5. Lebih mudah memanipulasi DOM
6. Dengan fasilitas filter dapat membuat aplikasi menjadi lebih fleksibel
7. Dan yg lebih penting adalah membuat kita _menulis kode dengan lebih ringkas_
