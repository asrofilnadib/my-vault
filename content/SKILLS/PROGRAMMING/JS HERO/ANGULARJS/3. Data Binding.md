## Introduction
Pada kali ini kita akan berkenalan dengan directive _ngModel_ yg merupakan kunci untuk mengerti penggunaan _two-way data-binding_.

Two-way data-binding atau binding dua arah adalah _sinkronisasi data secara otomatis antara model dan komponen sebagai view-nya_, setiap perubahan yg terjadi pada model akan berdampak pula pada view nya.

Format Penulisan :

```html
<tag ng-model="nama_model"></tag>
```

## Two-Way Data-Binding Pada Tag Input
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Latihan Angular</title>
    <script src="angular.min.js"></script>
</head>
<body ng-app>
    <input type="text" ng-model="namaku"> {{ namaku }}
</body>
</html>
```

Pada saat melakukan input pada textbox maka kata yg sama akan muncul di sebelahnya secara realtime.

## Two-Way Data-Binding Pada Tag Radio
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Latihan Angular</title>
    <script src="angular.min.js"></script>
</head>
<body ng-app>
    <h1>Latihan AngularJS</h1>
    <input type="radio" ng-model="makanan" value="Siomay">Siomay
    <input type="radio" ng-model="makanan" value="Sempol">Sempol
    <input type="radio" ng-model="makanan" value="Lontong">Lontong
    <p>Kamu memilih {{ makanan }}</p>
</body>
</html>
```

## Two-Way Data-Binding Pada Tag Select
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Latihan Angular</title>
    <script src="angular.min.js"></script>
</head>
<body ng-app>
    <h1>Latihan AngularJS</h1>
    <select ng-model="makanan">
        <option value="Siomay">Siomay</option>
        <option value="Sempol">Sempol</option>
        <option value="Lontong">Lontong</option>
    </select>
    <p>Kamu memilih {{ makanan }}</p>
</body>
</html>
```

## Two-Way Data-Binding Pada Tag Textarea

    <script src="angular.min.js"></script>
