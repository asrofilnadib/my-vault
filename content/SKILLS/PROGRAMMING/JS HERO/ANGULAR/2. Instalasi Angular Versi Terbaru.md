## Requirement
- NodeJS v.22

## Install
Buka terminal dan ketik

```shell
npm install -g @angular/cli
```

dan buat project

```shell
mkdir namaproject
ng new namaproject
```

Maka struktur folder akan seperti ini

<img src="Struktur Folder Angular Terbaru.png" width="250" align="left">















Terakhir jalankan server

```jsx
cd namaproject
ng serve
```

Dan akses localhost:4200
