## Instal Bootstrap
Anda dapat menginstal Bootstrap menggunakan npm. Buka terminal dan jalankan perintah berikut:

```shell
npm install bootstrap
```

## Angular.json
Load modules di angular.json

```json
"styles": [              
	"src/styles.css",              
	"node_modules/bootstrap/dist/css/bootstrap.min.css"            
],            
"scripts": [              
	"node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"            
]
```
