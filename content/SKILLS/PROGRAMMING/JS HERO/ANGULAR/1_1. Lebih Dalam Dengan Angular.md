## Introduction
"Angular is a web framework that empowers developers to build fast, reliable applications." Artinya Angular adalah framework web yg dapat diandalkan dan bisa membuat developer lebih cepat build aplikasi.

## Fitur Andalan
- **Opinionated component model** = Angular memiliki pendekatan tertentu tentang bagaimana sebaiknya komponen dibuat dan diatur — ini membantu developer untuk mengikuti struktur yang sudah disarankan.
- **Fine-grained reactivity** = artinya Angular "tahu persis" kapan dan di mana suatu data berubah, jadi dia cuma update bagian kecil dari halaman, bukan seluruh halaman.
- **Signals** = cara cerdas untuk mengatur perubahan data agar aplikasi tetap cepat dan efisien.
- **SSR (Server-Side Rendering)** : Halaman web dibuat di server dulu sebelum dikirim ke browser, biar lebih cepat terlihat.
- **SSG (Static Site Generation)** : Halaman dibuat duluan sebelum pengguna akses, cocok untuk situs statis.
- **Deferred Loading** : Muat bagian-bagian halaman secara bertahap, biar tidak overload. `@defer` adalah fitur di Angular yang bilang: “Bagian ini dimuat nanti, kalau udah perlu.”
