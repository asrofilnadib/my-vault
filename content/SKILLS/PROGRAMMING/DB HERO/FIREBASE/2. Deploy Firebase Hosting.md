## Introduction
Project Kali ini gue diwajibkan untuk melakukan hosting menggunakan firebase Hosting.

## Buat Project
![[firebase_hosting_1.png]]

- Silahkan klik “Create a Firebase Project

![[firebase_hosting_2.png]]

- Silahkan masukkan nama project kamu.

![[firebase_hosting_3.png]]

- Silahkan pilih “Hosting”
- Ketik perintah di cmd `npm install -g firebase-tools`
- Ketik perintah `firebase login` Maka anda akan dialihkan browser dan melakukan login google.
- Lalu ketik perintah `firebase init` lalu Ketik Y
- Pilih “Hosting: Configure files…” dengan tekan spasi lalu enter.
- Pilih “Use an existing project”
- Silahkan pilih project yg tadi sudah dibuat di akun firebase.
- langsung saja klik enter dan ketik y.
- Ralat, di pilihan “Set Up automatic build with github” Pilih N
- Sudah sampai tahap 3, isi nikname web app.
- Di step 4 lo bakal dikasih configurasi firebase nya. Coba di baca versi Firebase Laravel nya.
- Jangan lupa ketik perintah `npm run build`
- Terakhir silahkan ketik perintah `firebase deploy`

Note: Bila halaman website tidak sesuai coba untuk update file firebase.json kalian. arahkan public path ke dist (hasil build)

```json
{
  "hosting": {
    "public": "dist/namaproject(sesuaikan)/browser",
    "ignore": [
      "firebase.json",
      "**/.*",
      "**/node_modules/**"
    ],
    "rewrites": [
      {
        "source": "**",
        "destination": "/index.html"
      }
    ]
  }
}
```
