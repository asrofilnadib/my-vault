## Select
Digunakan untuk memilih data yg mau ditampilkan. 

Syntax:
```sql
SELECT column_1, column_2 FROM table_name;
```

Case:
```sql
SELECT NAME, code FROM country;
```

urutan kolom yg tampil sesuai dengan apa yg diketik duluan.

## Distinct
Digunakan untuk menampilkan value yg berbeda. Misal ada 5 negara yg sama, maka akan ditampilkan 1 negara saja.

Case:
```sql
SELECT DISTINCT continent FROM country;
```

## Where
Digunakan untuk filtrasi data yg ingin di tampilkan.

Syntax:
```sql
SELECT column1, column2  
FROM table_name  
WHERE condition;
```

Case:
```sql
SELECT name, code FROM country 
WHERE name = 'Indonesia';
```

## Order By
Digunakan untuk mengurutkan data berdasarkan kolom (A-Z / Z-A).

Syntax:
```sql
SELECT column1, column2  
FROM table_name  
ORDER BY column1 ASC;
```

Case:
```sql
SELECT name, code FROM country 
ORDER BY name ASC;
```

## And
Digunakan untuk filtrasi data seperti where tapi lebih dari 1.

Syntax:
```sql
SELECT column1, column2  
FROM table_name  
WHERE condition1 
AND condition2;
```

Case:
```sql
SELECT name, code 
FROM country 
WHERE continent = 'Asia'
AND name = 'Indonesia';
```

## Or
Digunakan untuk filtrasi data seperti where tapi lebih dari 1. Beda nya dengan AND itu kalau OR minimal harus 1 yg true.

Syntax:
```sql
SELECT column1, column2  
FROM table_name  
WHERE condition1 
OR condition2;
```

Case:
```sql
SELECT name, code 
FROM country 
WHERE continent = 'Asia'
OR name = 'Indonesia';
```

## NOT
Pengecualian. Misal gue ingin menampilkan data yg recordnya bukan asia.

Syntax:
```sql
SELECT column1, column2 
FROM table_name  
WHERE NOT condition;
```

Case:
```sql
SELECT name, code FROM country 
WHERE NOT continent = 'Asia';
```

## Null Value
Digunakan untuk mencari kolom kosong.

Syntax:
```sql
SELECT column_names  
FROM table_name  
WHERE column_name IS NULL;
```

Case:
```sql
SELECT name, code FROM country 
WHERE continent IS NULL;
```

## Insert Into
Digunakan untuk menambahkan data.

Syntax:
```sql
INSERT INTO table_name (column1, column2, column3)  
VALUES (value1, value2, value3);
```

Case:
```sql
INSERT INTO country (name, code, capital, continent)
VALUES ('Indonesia', 'IDN', 'Jakarta', 'Asia');
```

## Update
Digunakan untuk memperbarui data.

Syntax:
```sql
UPDATE table_name
SET column1 = value1, column2 = value2  
WHERE condition;
```

Case:
```sql
UPDATE country
SET name = 'Indonesia', code = 'IDN'
WHERE id = '1';
```

## Delete
Digunakan untuk menghapus data.

Syntax: 
```sql
DELETE FROM table_name WHERE condition;
```

Case:
```sql
DELETE FROM country WHERE id = '1';
```

## Min & Max
Digunakan untuk mencari angka terkecil dan terbesar.

Syntax:
```sql
SELECT MIN(column_name)  
FROM table_name;
```

Case: 
```sql
SELECT MIN(male)
FROM population;

SELECT MAX(male)
FROM population;
```

## Count
Digunakan untuk menghitung keseluruhan rows.

Syntax: 
```sql
SELECT COUNT(column_name)  
FROM table_name;
```

Case:
```sql
SELECT COUNT(total)
FROM gdp;
```

## Sum
Digunakan untuk mengkalkulasi angka di salah satu kolom.

Syntax:
```sql
SELECT SUM(column_name)  
FROM table_name;
```

Case:
```sql
SELECT SUM(total)
FROM gdp;
```

## AVG
Digunakan untuk mencari nilai rata-rata.

Syntax:
```sql
SELECT AVG(column_name)  
FROM table_name;
```

Case:
```sql
SELECT AVG(total)
FROM gdp;
```

## Like
Digunakan untuk mencari data.

Syntax:
```sql
SELECT column1, column2  
FROM table_name  
WHERE column LIKE pattern;
```

Case:
```sql
SELECT name
FROM country
WHERE name LIKE 'Ind%';
```

## In
Digunakan untuk mencari lebih dari 1 data dalam 1 statement. In adalah versi sederhana nya dari where nested.

Syntax:
```sql
SELECT column_name(s)  
FROM table_name  
WHERE column_name IN (value1, value2);
```

Case:
```sql
SELECT * FROM country
WHERE name IN ('Indonesia', 'Qatar');
```

## Between
Digunakan untuk mencari data range. bisa berupa angka, teks, dan date.

Syntax:
```sql
SELECT column_name(s)  
FROM table_name
WHERE column_name BETWEEN value1 AND value2;
```

Case:
```sql
SELECT * FROM country
WHERE total BETWEEN 10 AND 20;
```

## Alias
Digunakan untuk merubah nama kolom sementara supaya lebih mudah dibaca.

Syntax:
```sql
SELECT column_name AS alias_name  
FROM table_name;
```

Case:
```sql
SELECT name AS negara
FROM country;
```

## GroupBy
Digunakan untuk

Syntax:
```sql
SELECT Country  
FROM Customers  
GROUP BY Country;
```

Case:
```sql
SELECT name, continent 
FROM country 
GROUP BY continent;
```

## Having
Mirip dengan where, namun where tidak bisa agregate (angka).

Syntax: 
```sql
SELECT column_name(s)  
FROM table_name  
HAVING condition;  
```

Case: 
```sql
SELECT * FROM country
HAVING name = 'Indonesia';
```

## Exists
Digunakan untuk mengecek keberadaan data dalam sub query.

Syntax:
```sql
SELECT column_name(s)  
FROM table_name
WHERE EXISTS  
(SELECT column_name FROM table_name WHERE condition);
```

Case:
```sql
SELECT * FROM country
WHERE EXISTS (
	SELECT total FROM poverty
	WHERE poverty.country_id = country.id
);
```

## Case
Digunakan untuk logika kondisi seperti if elseif else.

Syntax:
```sql
CASE  
    WHEN condition1 THEN result1  
    WHEN condition2 THEN result2  
    ELSE result  
END;
```

Case:
```sql
SELECT OrderID, Quantity,  
CASE  
    WHEN Quantity > 30 THEN 'The quantity is greater than 30'  
    WHEN Quantity = 30 THEN 'The quantity is 30'  
    ELSE 'The quantity is under 30'  
END AS QuantityText  
FROM OrderDetails;
```
sumber: W3school

## Comment
Digunakan untuk menandakan kode. cukup tambahkan `--`.

Case:
```sql
SELECT 
-- name,
code,
capital
FROM country;
```
