## Create

```sql
CREATE DATABASE nama_database;
```
Diatas adalah perintah untuk membuat database baru

## Drop

```sql
DROP DATABASE nama_database;
```
Diatas adalah perintah untuk menghapus database.

## Alter Database

```sql
ALTER DATABASE gdp MODIFY NAME = gdp_ku;
```
Note: bisa  di run di SQL Server

## Backup

```sql
BACKUP DATABASE gdp
TO DISK "D:\gdp_indo.bak";
```
Note: bisa  di run di SQL Server
