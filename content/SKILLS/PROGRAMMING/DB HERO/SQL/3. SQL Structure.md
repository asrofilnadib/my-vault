## Create Table
Syntax:
```sql
CREATE TABLE table_name (  
    column1 datatype,  
    column2 datatype,  
    column3 datatype,  
);
```

Case:
```sql
CREATE TABLE pengguna (
	id INT,
	nama_depan VARCHAR(128),
	nama_belakang VARCHAR(128),
	nama_lengkap VARCHAR(128),
	umur INT 
);
```

Note: id belum auto increment, secara default null semua. Ada case dimana data tidak boleh kosong. Akan dijelaskan lebih lengkap.

Selengkapnya: https://dev.mysql.com/doc/refman/8.0/en/data-types.html atau https://www.w3schools.com/sql/sql_datatypes.asp

## Drop Table
Syntax:
```sql
TRUNCATE TABLE table_name;
```

Case:
```sql
TRUNCATE TABLE pengguna;
```

Menghapus table yg ditentukan.

## Alter Table
### Add Column
Syntax:
```sql
ALTER TABLE table_name 
ADD column_name datatype;
```

Case:
```sql
ALTER TABLE pengguna
ADD hoby VARCHAR(50);
```

### Drop Column
Syntax:
```sql
ALTER TABLE table_name
DROP COLUMN column_name;
```

Case:
```sql
ALTER TABLE pengguna
DROP COLUMN hoby;
```

### Rename Column
Syntax:
```sql
ALTER TABLE table_name  
CHANGE COLUMN old_name new_name datatype;
```

Case:
```sql
ALTER TABLE pengguna             
CHANGE COLUMN umur tahun TINYINT;
```

## Index
Untuk pengambilan data yg lebih cepat dalam hal pencarian (searching data). Pengguna tidak bisa melihat index namun hanya mempercepat pencarian query. Buatlah Index pada kolom yg sering dicari.

Syntax:
```sql
CREATE INDEX nama_index
ON table (column);
```

Case:
```sql
CREATE INDEX NamaLengkap
ON pengguna (nama_lengkap);
```

## View
Intinya view ini untuk mempersingkat table yg sesuai dengan kita ingin tampilkan. Misal ada 10 kolom dan yg sering dilihat oleh pengguna ada 3. Jadi kita jatuhnya buat table virtual sesuai dengan pengguna butuhkan.

Note: Ketika kita hapus data di view maka di parent nya akan hilang juga. Begitupun dengan update data. Be aware...

Syntax:
```sql
CREATE VIEW view_name AS  
SELECT column1, column2  
FROM table_name  
WHERE condition;
```

Case:
```sql
CREATE VIEW pengguna_view AS
SELECT nama_lengkap, umur
FROM pengguna
WHERE umur = '24';
```
