## Join
Digunakan untuk menggabungkan rows dari 2 table atau lebih.

![[Pasted image 20251021211331.png]]
Sumber: W3School

Penjelasan:
1. Inner Join: hanya menampilkan **baris yang cocok** di kedua tabel.
2. Left Join: Menampilkan **semua data dari tabel kiri (Tabel 1)**, dan hanya data yang cocok dari tabel kanan (Tabel 2).
3. Right join: menampilkan **semua data dari tabel kanan (Tabel 2)**, dan hanya data yang cocok dari tabel kiri (Tabel 1).
4. Full join: menampilkan **semua data dari kedua tabel**, baik yang cocok maupun tidak. (Tidak mendukung di Mysql)

## Inner Join
`INNER JOIN` hanya menampilkan **baris yang cocok di kedua tabel**.

Syntax:
```sql
SELECT column_name(s)  
FROM table1  
INNER JOIN table2  
ON table1.column_name = table2.column_name;
```

Case:
```sql
SELECT name, total 
FROM country
INNER JOIN gdp 
ON country.id = gdp.country_id;
```

## Left Join
Semua baris dari **tabel kiri** (di sebelah `FROM`) akan ditampilkan, ditambah data dari tabel kanan jika cocok. Jika tidak cocok, kolom dari tabel kanan diisi `NULL`.

Syntax:
```sql
SELECT column_name(s)
FROM table1
LEFT JOIN table2  
ON table1.column_name = table2.column_name;
```

Case:
```sql
SELECT name, total 
FROM country
LEFT JOIN gdp 
ON country.id = gdp.country_id;
```

## Right Join
Semua baris dari **tabel kanan** (yang di-join) akan ditampilkan, ditambah data dari tabel kiri jika cocok. Jika tidak cocok, kolom dari tabel kiri diisi `NULL`.

Syntax:
```sql
SELECT column_name(s)
FROM table1
RIGHT JOIN table2  
ON table1.column_name = table2.column_name;
```

Case:
```sql
SELECT name, total 
FROM country
RIGHT JOIN gdp 
ON country.id = gdp.country_id;
```
