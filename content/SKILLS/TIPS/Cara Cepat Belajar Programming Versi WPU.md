## Introduction
Ngga ada cara cepat belajar programming. Semuanya membutuhkan proses yg panjang dan kalian harus terus menerus belajar. Setiap orang berbeda-beda proses pembelajarannya. Lalu definisi cepat untuk setiap orang berbeda. Berikut Cara Cepat Belajar Programming

## 1. Project Based Learning
Pembelajaran berbasis project artinya setiap belajar sesuatu, terapkan kedalam sebuah project dari pemahaman yg sudah didapatkan. Jadi belajarnya tidak harus panjang-panjang. Belajar sedikit, terapkan! Hindari belajar banyak di satu waktu karena bisa buat kita bosan.

Saran saya kamu harus memiliki tempat bermain atau playground untuk melakukan eksperimen pada topik yg sedang dipelajari. Biasanya berbentuk website portfolio kalian.

## 2. ATM (Amati Tiru Modifikasi)
Mungkin teman-teman sering mendengarnya. Biasanya kalau kamu ikut tutorial, atau online course tidak sedikit dari kalian berhenti hanya di bagian tiru nya saja. Saran saya buatlah sesuatu yg benar-benar beda dari apa yg sedang dipelajari menggunakan ilmu yg telah didapatkan.
