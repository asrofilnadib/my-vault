## 1. Tidak Belajar Bahasa Inggris
Tidak berusaha untuk belajar bahasa inggris. Kalian tidak perlu belajar bahasa inggris sampai fasih. Bahasa inggris di programming itu ketika kita sudah nyaman dan mampu membaca dokumentasi teknis dan digunakan untuk mencari solusi bilamana terjadi error syntax.

Kemampuan berbahasa inggris untuk programmer sangat penting. Sambil belajar Programming sambil diasah skill berbahasa inggris.

## 2. Tidak Membaca Pesan Error
Banyak sekali terjadi buat teman-teman yg baru belajar, lagi sekolah, lagi kuliah. Solusi sederhana dari error yg kalian dapatkan ada di baris error itu sendiri. Luangkan waktu untuk membaca pesan error.

## 3. Tidak Membaca Dokumentasi Resmi
Tidak membaca dokumentasi resmi dari teknologi yg kita pelajari. Bisa bahasa pemrograman, bisa library, bisa framework, dll. Setiap teknologi tersebut punya websitenya sendiri, punya dokumentasi resminya sendiri.

**Jadikan dokumentasi resmi sebagai acuan utama.**

## 4. Menghafal Koding
Kita berusaha untuk menghafal koding, perlu dipahami bahwa _koding bukan untuk dihafal, tapi dipahami!_. Tidak mungkin kita menghafal semua syntax yg telah kita tulis. Setiap mereka punya karakteristik yg berbeda, sintaks yg berbeda.

Bila memahami bahasa inggris, ini mempermudah kita untuk tidak menghafal. Bahasa inggris juga membantu kita mengurangi apa yg harus kita hafal. Jadi yg harus dipahami adalah konsep programmingnya.

> Hampir semua bahasa pemrograman punya konsep yg namanya variabel,tipe data,pengulangan,pengkondisian. Yg membedakan itu hanya syntax. Selama kita paham konsepnya, kita tinggal cari tahu cara penulisannya bagaimana.

## 5. Tidak Memahami Fundamental
Biasanya terjadi ketika kita ingin buru-buru untuk memahami teknologi tertentu tanpa kita tahu pre-requisite nya. Setiap bahasa pemrograman ada benang merahnya, ada karakteristik tersendiri.

Ada orang 2 minggu sudah jago di framework A,B,C. karena mereka sebelumnya sudah memiliki pengalaman di dunia programming.

## 6. Tidak Mengenali Tools
Tidak memahami tools pendukung seperti kode editor, atau IDE, web browser. Ketika menggunakan teks editor kita harus memahami plugin, add-on, atau ekstensi browser untuk mempermudah kita belajar programming.

## 7. Tidak Menggunakan Version Control
Penting sekali bagi kita programmer untuk tahu cara menggunakan _Version Control System (VSC)_. Contoh kita dapat menggunakan GIT dan Github. Kalian lakukan minimal mengelola kode kalian sendiri. Untuk tugas kuliah, sekolah coba untuk simpan semua ke github.

## 8. Terjebak di Tutorial HELL
Istilah yg sering muncul ketika kita mengikuti tutorial dan selesai mengikuti tutorial kita sudah merasa sudah paham, padahal Belum. Seringkali ketika kita mengangkat ke kasus yg berbeda kita kerapkali bingung itu artinya kalian belum paham.

## 9. Tidak Percaya Diri
Tidak percaya diri dengan apa yg kalian buat. Kadang kita sudah belajar, Kita merasa apa yg kita buat tidak bagus. Wajar namanya juga masih belajar.

## 10. Membandingkan Diri
Seringkali kita insecure dengan pencapaian orang lain. klau kita mengalami itu, pahami bahwa semua orang itu _BEDA_. Kita tidak pernah tahu apa yg orang lain alami. Bisa jadi dia bisa 2 minggu belajar, namun kita tidak tahu bahwa dia berapa lama bergadang dalam 1 minggu?

"Fokus aja pada apa yg bisa kita kendalikan."
