## Introduction
Zaman semakin canggih, kita dituntut untuk mengikuti perkembangan zaman. Bila diingat-ingat menjadi programmer sebelum era AI (Artificial Inteligence), bisa dikatakan sangat memakan waktu. Gue inget banget buat 1 aplikasi aja bisa 2 - 3 bulan. Sekarang 1 aplikasi bisa 1 bulan (estimasi jika requirement jelas dan lumayan kompleks).

## Gemini Code Assist
AI dari Google, yang dirancang untuk membantu developer dalam berbagai tugas, mulai dari menulis kode hingga menguji dan memperbaiki kesalahan. Menurut gue Gemini Code Assist sangat membantu gue dalam developing program.

![[Gemini_Code_Assist(1).png]]

Install ekstensi "Gemini Code Assist" di VSCode.
Hal yg gue suka itu:
1. Nempel di vscode, tanpa alt tab mondar-mandir ke browser. Ribet!
2. Kita bisa langsung menargetkan file dengan ketik `@nama_file` Ini tanda nya lebih terfokus pada problem kita.
3. Lebih cepat karena lebih terfokus. Gemini tidak ngalor-ngidul dan bertele-tele.
4. Suggest code sangat cepat.
