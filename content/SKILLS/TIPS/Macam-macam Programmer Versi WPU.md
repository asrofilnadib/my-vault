## Introduction
_Apa sih beda nya programmer, software developer hingga software engineer?_

Secara umum Coder, Programmer, Software Developer, Software Engineer itu semuanya _sama_! Intinya semuanya itu _Ngoding!_

"A computer programmer sometimes referred to as a _software developer_, a _software engineer_, a _programmer_, or more recently a _coder_, is a person who _creates computer software_" - Wikipedia "Computer Programmer"

Seorang programmer komputerkadang-kadang disebut sebagai software developer, software engineer, programmer atau bahkan akhir-akhir ini disebut coder. Seseorang yg membuat perangkat lunak komputer. -Wikipedia

Menurut saya ada hirarki di dunia programming. Berikut hirarki nya :

## 1.0 Coder
Kita awalnya seorang Coder. Coder adalah seseorang yg nulis kode. Menulis kode ini ngga peduli mau 1 baris atau ribuan baris, menggunakan bahasa pemrograman apapun, itu sama-sama nulis kode.

## 2.0 Programmer
Seorang programmer pasti coder. Programmer adalah orang yg bikin program.

"A computer program is a sequence of instruction in a programming language that a computer can _execute_ and _interpret_" -Wikipedia

Sebuah program di komputer kita adalah serangkaian instruksi yg ditulis menggunakan bahasa pemrograman yg bisa dieksekusi atau di interpretasi. Klo aplikasi pasti di eksekusi, tapi kalau web itu di interpretasi.

Jika kamu pernah membuat aplikasi sederhana seperti membuat website, kalkulator, game itu sudah bisa dikatakan kita adalah programmer.

## 3.0 Software Developer
Seorang Software developer pasti programmer, dan coder.

"Software development is the process of _planning_, _specifying_, _designing_, _programming_, _documenting_, _testing_, _bug_, _fixing_, and _maintaining_ application, framework, or other software components" - Wikipedia

Pengembangan perangkat lunak adalah proses dari perencanaan, penentuan, perancangan, pembuatan program, dokumentasi, perbaikan bug dan perawatan dari sebuah aplikasi, framework, atau software lain.

Programming termasuk salah satu dari proses pengembangan perangkat lunak.

Pengembangan perangkat lunak biasa kita kenal _SDLC (Software Development Lifecycle)_

Jika kamu membuat program tanpa dokumentasi itu namanya programmer, namun jika kamu menggunakan tahap SDLC ini kamu bisa disebut software developer.

## 4.0 Software Engineer
Seorang Software Engineer pasti software developer, programmer, dan coder. Software Engineer bisa kita sebut orang yg merekayasa perangkat lunak atau bisa kita sebut juga _insinyur perangkat lunak_.

"A Software Engineer ia a person who applies the _principles of software engineering_ to design, develop, maintain, test, and evaluate computer software" -Wikipedia

Orang yg menerapkan prinsip prinsip rekayasa perangkat lunak pada saat merancang, mengembangkan, menguji, dan mengevaluasi perangkat lunak.

Sama seperti software developer, namun software engineering menerapkan prinsip-prinsip rekayasa perangkat lunak.

Contoh Prinsip-prinsip Software Engineering :

1. Rigor and Formality : ketegasan dan formalitas. sebuah software harus ada ketegasan dan tidak boleh asal-asalan.
2. Separation of Concerns : pemisahan kepentingan atau kebutuhan.
    1. Modularity & Abstraction : memecah program menjadi bagian kecil
3. Anticipation of Change : software yg kita buat bisa mengantisipasi perubahan kedepannya.
4. Generality
5. Incremental Development
6. Consistency
7. KISS (Keep it Simple Stupid!) : gimana cara kita bikin program itu tidak terlalu rumit, sehingga program kita bisa dipahami oleh team kita.
8. DRY (Don't Repeat Yourself) : Jangan lakukan hal yg sama, tapi bisa kita abstaksiin menjadi sebuah modul.
9. YAGNI (You Aren't Going to Need It!) : mencari atau menentukan mana saja yg penting untuk aplikasi kita
10. SOLID
    - Single Responsibility Principle
    - Open Closed Principle
    - Liskov Substitution Principle
    - Interface Segregation Principle
    - Dependency Inversion Principle

Ada hal-hal yg harus diterapkan diluar dari proses pembuatan perangkat lunaknya saja.
