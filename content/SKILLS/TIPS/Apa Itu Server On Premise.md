## Apa Itu On Premise?
_On premise_ adalah sebuah sistem penyimpanan dan pengolahan data yang dikelola langsung oleh tim internal IT perusahaan serta berada di sebuah gedung. Server ini memiliki perbedaan dengan sistem _cloud_ karena basis datanya _online_.

Secara sederhana, _on premise_ artinya merujuk pada penggunaan server in house dengan melibatkan tim IT perusahaan. Maka dari itu, server ini bukanlah jaringan server remote seperti _cloud_.

Kondisi ini membuat pemilik _server on premise_ memberikan lisensi penuh kepada tim IT untuk mengelola basis data yang ada di dalamnya.

_Server on premise_ pun juga diandalkan oleh beberapa perusahaan modern karena mempunyai tingkat kontrol yang tinggi.

## Kelebihan On Premise
**1. Kontrol penuh perusahaan**
Kelebihan pertama penggunaan _on premise_ adalah perusahaan mempunyai kontrol atau kendali penuh ketika menggunakannya. 

Hal ini berarti perusahaan memiliki kebebasan untuk membuat server sendiri. Server ini memungkinkan perusahaan untuk mengakses semua data.

**2. Implementasi bebas oleh perusahaan**
Selanjutnya, kelebihan _on premise_ adalah perusahaan bebas untuk mengimplementasikan server yang sudah dibuat sebelumnya. Hal ini tidak lepas dari hak kepemilikan terhadap server tersebut.

Implementasi di sini berarti perusahaan dan tim IT akan mengelola secara penuh terhadap server yang nantinya digunakan oleh _user_, sehingga bisa meningkatkan efisiensi dalam bekerja.

**3. Kustomisasi** 
Kelebihan lain yaitu perusahaan memiliki fleksibilitas yang bisa disesuaikan oleh sistem dengan kebutuhan bisnisnya. Mereka pun bebas untuk melakukan kustomisasi _server_ sesuai kebutuhan user.

## Kekurangan On Premise
**1. Biaya investasi infrastruktur tinggi** 
Ketika menggunakan _on premise_, maka dibutuhkan investasi awal yang cukup besar untuk mendukung infrastruktur IT. Hal ini tidak lepas dari banyaknya sumber daya dan tools yang harus disiapkan.

Investasi atau biaya ini dibagi menjadi beberapa aspek, mulai dari pembelian dan pemasangan hardware (server, jaringan, dan penyimpanan), rekrutmen staff, hingga lisensi dari software.
